# My QA Learning Journey

Hi! This repository is where I keep my first projects and practice tasks while learning Manual QA.

I'm starting from scratch and currently practicing on [Swag Labs](https://www.saucedemo.com/). I'm using this demo website to learn how to test features, find issues, and document them properly.

## What I'm learning

- Writing test cases
- Finding and reporting bugs
- Testing login and shopping cart functionality
- Checking product sorting and navigation
- Exploratory testing
- Using browser DevTools

## Current project: Swag Labs

So far, I've tested login, product sorting, and adding and removing items from the shopping cart.

While testing with the `problem_user` account, I noticed several issues. Some products could not be added to the cart, some product images did not match the items, and some links opened the wrong product pages.

I'm still learning how to document these findings clearly and check when the issues can be reproduced.

## Test environment

- Windows 11
- Google Chrome

## Repository structure

- `test-cases/` — test cases I've written
- `bug-reports/` — bugs I've found and documented
- `exploratory-testing/` — notes from exploratory testing
- `evidence/` — screenshots and other evidence

This is a work in progress. I'll keep adding to it as I learn more and get more practice.
